# AMSALOR: Ecos de un Muerto

> Un RPG ASCII desarrollado completamente en HTML, CSS y JavaScript.

## ¿Qué es?

Amsalor es un RPG de exploración y combate donde toda la experiencia está construida utilizando únicamente texto y caracteres ASCII.

El proyecto busca demostrar que un videojuego no necesita gráficos complejos para ofrecer exploración, estrategia, progresión y una identidad propia.

Todo el juego está contenido en un único archivo HTML, sin motores externos ni dependencias.

## Filosofía

Amsalor nació como un desafío personal.

Quería comprobar hasta dónde podía llegar un videojuego utilizando únicamente las tecnologías básicas de la web y una interfaz basada en caracteres.

En lugar de invertir recursos en gráficos complejos, el objetivo es dedicar ese esfuerzo al diseño de sistemas, mecánicas y jugabilidad.

Cada elemento intenta tener un propósito, evitando añadir características únicamente por ser llamativas.

## Características actuales

- Mundo explorado mediante gráficos ASCII.
- Combate táctico.
- Sistema de progresión del personaje.
- Inventario y equipamiento.
- Interfaz completamente desarrollada desde cero.
- Compatible con navegadores modernos.
- Funciona sin instalación.

## Tecnología

- HTML
- CSS
- JavaScript puro (Vanilla JS)

No utiliza motores de videojuegos ni frameworks.

## Estado del proyecto

Amsalor continúa en desarrollo.

Muchas mecánicas siguen siendo experimentales y el contenido continúa creciendo con cada versión.

El objetivo es construir un RPG cada vez más profundo manteniendo la simplicidad técnica del proyecto.
